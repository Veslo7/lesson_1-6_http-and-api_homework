# ДЗ 6. База учебных встреч

Frontend-клиент для учебного REST API на `json-server`. Приложение показывает список учебных встреч (лекции, практикумы, разборы) и позволяет добавлять, изменять и удалять их.

## Ресурс и endpoint

```text
http://localhost:3000/meetups
```

| Метод | URL | Назначение |
| --- | --- | --- |
| `GET` | `/meetups` | список встреч (поддерживает фильтры и сортировку) |
| `POST` | `/meetups` | создать встречу |
| `PATCH` | `/meetups/:id` | изменить встречу |
| `DELETE` | `/meetups/:id` | удалить встречу |

## Модель данных

```json
{
  "id": "1",
  "title": "Fetch API без магии",
  "topic": "frontend",
  "startsAt": "2026-10-22T18:30",
  "durationMinutes": 90,
  "capacity": 24,
  "host": "Анна Ковалёва",
  "isOnline": true
}
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `title` | строка | название встречи |
| `topic` | строка | направление: `frontend`, `backend`, `design`, `career` |
| `startsAt` | строка (дата и время) | начало встречи в формате `YYYY-MM-DDTHH:mm` |
| `durationMinutes` | число | длительность в минутах |
| `capacity` | число | количество мест |
| `host` | строка | ведущий |
| `isOnline` | логическое | онлайн или очно |

`id` назначает `json-server`.

## Запуск

Понадобятся Node.js `22.12` или новее, npm и VS Code с расширением Live Server.

API:

```bash
cd backend
npm ci
npm run dev
```

После запуска откройте http://localhost:3000/meetups — должен вернуться JSON со списком встреч.

Frontend:

1. Откройте `frontend/index.html` в VS Code.
2. Запустите **Open with Live Server**.
3. API должен быть запущен на `http://localhost:3000`.

## Что реализовано

Базовая часть:

- загрузка коллекции через `GET` с проверкой `response.ok`;
- состояния: загрузка, список, пустой список, ошибка с кнопкой повтора;
- безопасный вывод карточек через DOM и `textContent`;
- форма с HTML-валидацией, сбор данных через `FormData`, приведение типов, отправка `POST`;
- блокировка повторной отправки, очистка формы только после успеха, повторный `GET`.

Дополнительная часть:

- **A1** — серверная фильтрация (направление, формат), поиск и сортировка через query-параметры, сброс фильтров;
- **A2** — удаление встречи через `DELETE` с подтверждением;
- **A3** — редактирование через `PATCH` с отменой и сохранением введённых данных при ошибке;
- **B1** — поиск с debounce и отменой предыдущего запроса через `AbortController`;
- **B3** — ограничение времени ожидания запроса с отдельным сообщением о тайм-ауте.
